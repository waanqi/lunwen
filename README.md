# 基于刚柔结合折纸结构的假肢手腕系统设计研究

## 论文基本信息

- 论文题目：《基于刚柔结合折纸结构的假肢手腕系统设计研究》
- 研究方向／专业：设计学—工业设计
- 学校／学院：浙江工业大学设计与建筑学院
- 研究对象：刚柔耦合 Kresling 假肢腕部系统
- 控制方案：采用健—患侧联动控制，对患者健侧肢体的手势动作信号进行分类识别，并将分类结果映射为患侧假肢控制指令
- 系统构成：刚柔耦合 Kresling 腕关节、健—患侧手势分类控制模块，以及可替换的假肢手掌、夹具和其他专用工具头

## 研究定位

本研究以设计学的“问题—用户—策略—设计—原型—情境评价”为主线，探索刚柔耦合折纸结构在假肢腕部系统中的应用。论文不仅关注结构功能能否实现，也关注系统在日常生活活动中的任务适配、控制体验、模块换装与使用价值，避免写成以机械参数为唯一核心的工程论文。
