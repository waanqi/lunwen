## 分类关注点

### 结构功能

记录运动模式、运动范围、重复性、稳定性、柔顺适应、安全边界和失效情况；参数必须能回扣设计需求。

### 运动控制

分别记录健侧腕部连续跟随与手指／按键离散指令，包括标定、映射关系、准确性、延迟、模式误触和学习过程。

### 末端换装

记录手掌、夹具及其他工具头的接口兼容性、换装步骤、时间、锁定确认、单手操作可能性和异常脱落情况。

### ADL 任务

记录任务来源、情境、成功标准、完成情况、时间、错误、辅助程度及不同工具头的适配性。

### 用户可用性

记录易学性、操作负担、舒适性、控制感、安全感、接受度和访谈反馈；主观评价不得替代客观性能数据。
