# 硕士论文协作工作流

## Step 0：A 指派 C 读取状态

A 明确指派只读检查的范围后，C 检查 `thesis_state.md` 和经授权的 Git 状态，向 A 报告当前进度、未提交修改、当前远程配置、预期远程目标及阻塞项。不得在此步骤自行修改或提交。

## Step 1：A 向 B 下达任务

A 每次只向 B 下达边界清楚的单节写作任务或纯文献任务。正文任务说明：

- 本节要回答的问题；
- 必须形成的论点；
- 需要检索的文献方向；
- 可使用的现有材料；
- 禁止虚构和不得提前下结论的部分；
- 提交格式与验收标准。

纯文献任务须说明检索主题、证据用途、来源与核验要求、时间或主题边界、禁止事项和验收标准，不强制生成正文。

## Step 1.5：A 指定风格样本，B 建立风格画像

仅在确有风格参考需要时，A 指定主样本 1 篇、辅助样本最多 2 篇及其具体章节或页码，并说明适用的章节类型。B 必须先基于本论文任务与证据建立独立内容提纲，再按指定范围填写 `style-references/style_reference_card.md`，随后脱离样本原文独立写作。B 不得每轮遍历全部参考文献；同类章节可复用已经 A 审核的风格画像。

风格分析仅提炼句法节奏、段落推进、论证组织和文献嵌入等抽象特征，不得复制、拼贴、贴近改写或逐句同义替换样本文本，也不得把风格阅读当作文献检索、事实核验或引用依据。

## Step 2：B 完成文献核验和 Markdown

B 阅读 `AGENTS.md`、本工作流、规则、大纲、状态与 A 的指令；涉及图片时读取 `figures/README.md`，涉及引用时读取已有的 `references/references.bib`（若存在）。B 完成真实文献检索核验和获准的 Markdown 正文；纯文献任务可只提交核验报告。正文引用仅使用已入库且核验通过的 `[@key]`；新增文献须提交真实完整元数据、核验来源、DOI 或 URL（若有）和建议 key，不得声称未入库 key 已可用。缺失实验数据写 `[待补充实验数据]`。

## Step 3：A 审核正文

A 按以下维度审核：

1. 研究方向是否正确；
2. 论证逻辑是否自洽；
3. 与前后章节是否重复；
4. 事实、引用和结论是否有充分证据；
5. 术语是否符合 `writing_rules.md`；
6. 是否保持设计学定位；
7. 实验占位是否诚实、清楚且未伪造数据；
8. 是否存在机械同构、抽象名词堆叠或对样本特有措辞、句序和段落骨架的依赖；
9. 风格参考与内容证据是否明确分离，直接引用是否规范标注。

A 必须给出一种明确结论：

- **通过**：可进入技术落地；
- **有条件通过**：B 完成指定小修并由 A 确认后才可进入技术落地；
- **退回修改**：不得交给 C 转换。

## Step 4：C 技术落地并展示 diff

只有 A 明确通过后，C 才可：

1. 将 Markdown 转换为 LaTeX；
2. 将已核验引用写入 `references/references.bib`；
3. 执行编译并检查错误、警告、交叉引用和参考文献；
4. 按 A 指令更新 `thesis_state.md`，并将该更新纳入本轮完整 diff；
5. 向 A 展示或报告完整 diff 与编译状态。

新增 BibTeX 条目前，C 必须核验来源元数据并检查建议 key 是否与现有 `references/references.bib` 冲突；文件不存在时，仅在 A 明确授权新建后创建。发现 key 冲突、元数据不完整或文献未核验时停止相应引用入库并报告。

此步骤不得 commit、push 或同步 Overleaf。

## Step 5：A 确认后提交与同步

A 审阅 C 的完整 diff 和编译结果。A 必须分别明确授权下列操作；未获授权的项目不得执行：

1. Git commit：确认提交范围与提交说明；
2. GitHub push：复核当前远程配置与目标分支后执行；
3. Overleaf 同步：复核目标项目与同步方向后执行；
4. 报告提交号、远程分支与同步结果。

## Step 6：确认状态并继续

C 核对 Step 4 已纳入 diff 的 `thesis_state.md`，并在 A 另有授权时补记 Step 5 的提交与同步结果。补记完成后，C 必须先向 A 报告该次 `thesis_state.md` diff；只有 A 再次确认该 diff 并明确授权相应操作时，C 才可继续执行后续 commit、GitHub push 或 Overleaf 同步。未获授权时，该状态更新保留为未提交修改，C 向 A 报告后停止。A 验收状态记录后规划下一节，回到 Step 1。

## 阻断条件

出现以下任一情况时，相关流程必须停止：

- 存在虚假、占位或未核验引用；
- 存在伪造或无法追溯的数据、访谈或实验结果；
- A 尚未通过正文；
- Git 仓库、远程地址、目标分支或提交范围不明确；
- LaTeX 编译失败；
- GitHub 或 Overleaf 存在远程冲突；
- 权限、伦理或知情同意状态不允许继续。

## 文件交接约定

- B 的正文写入：`chapters/chXX_*.md`
- 经核验的文献写入：`references/references.bib`
- 当前进度与风险写入：`thesis_state.md`
- 图片及占位规则参照：`figures/README.md`
- 实验记录参照：`experiments/README.md`
