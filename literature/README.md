# 文献笔记说明

## 用途

本目录用于保存已经定位到原始来源的文献笔记，为章节写作、BibTeX 引用和证据核验提供依据。不得只记录参考论文、公众号或搜索摘要中的二手转述。

## 命名建议

`年份_第一作者_题名关键词.md`

示例：`2024_Zhang_prosthetic_wrist.md`

## 每篇文献笔记必须包含

```markdown
# 文献题名

## 完整元数据
- 作者：
- 年份：
- 题名：
- 期刊／会议／学位授予单位：
- 卷（期）与页码：
- DOI：
- 原文 URL：
- 文献类型：
- BibTeX key：

## 核验状态
- [ ] 元数据已核验
- [ ] DOI/URL 已核验
- [ ] 已阅读摘要
- [ ] 已阅读全文
- 状态：[VERIFY] / 已核验

## 研究问题

## 研究方法

## 样本／装置

## 关键结果

## 可引用观点
- 观点：
- 原文位置（页码／章节／图表）：
- 可支持的论文段落：

## 研究局限

## 与本论文的关系
- 对应章节：
- 用途：背景／理论／方法／比较／讨论

## 备注
```

## 使用规则

- 完整元数据、DOI 或稳定 URL 缺失时标记 `[VERIFY]`。
- “可引用观点”必须注明原文位置，且不得扩大原作者结论。
- 综述可以用于建立线索，但关键论断应尽量回溯原始研究。
- 任何由 AI 生成的文献信息均须人工核验后方可进入正式 BibTeX。
- 对撤稿、勘误、预印本和非同行评审来源单独标注。
