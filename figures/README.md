# 论文图片管理说明

## 基本要求

每幅图片必须记录：

- 暂定／正式图号；
- 中文图题，必要时附英文图题；
- 可编辑源文件位置；
- 论文使用的导出文件；
- 导出格式与分辨率；
- 数据、照片、模型或文献来源；
- 版权、授权和匿名化状态；
- 对应章节和正文引用位置；
- 制作、审核与定稿状态。

## 文件与导出建议

- 结构图、流程图和图表优先保留 SVG、AI、PDF 等矢量源文件。
- 照片和渲染图使用高分辨率 PNG/TIFF，并保留未经压缩的原始文件。
- 同一图片的源文件和导出文件应使用一致的语义化名称。
- 禁止使用来源不明、无法授权或无法追溯数据的图片。
- 改绘文献图片仍须注明原始来源，不得以“自绘”掩盖他人内容。
- 涉及参与者影像时，必须确认知情同意、匿名化与发表授权。

## 正文占位符格式

统一使用：

```markdown
<!-- FIGURE: Fig.X-X | 标题 | 来源/待制作 | 状态 -->
```

示例：

```markdown
<!-- FIGURE: Fig.1-X | 论文研究框架 | 作者自绘 | 候选，待定编号 -->
```

## 图片登记表

| 候选编号 | 图片名称 | 现有文件 | 来源 | 对应章节 | 状态 |
|---|---|---|---|---|---|
| 图1-X | 论文研究框架图 | `../研究框架图_三栏式.svg`、`../研究框架图_三栏式.png` | 作者自绘 | 第一章 1.4 或 1.6 | 候选，最终编号待定 |

## 单图记录模板

```markdown
### Fig.X-X 图片标题

- 源文件：
- 导出文件：
- 格式／尺寸／分辨率：
- 数据或内容来源：
- 版权／授权状态：
- 对应章节：
- 正文首次引用位置：
- 图注：
- 状态：待制作／修改中／待审核／已定稿
- 备注：
```
