# 章节正文说明

## 文件命名

| 章节 | Markdown 文件 |
|---|---|
| 第一章 绪论 | `ch01_intro.md` |
| 第二章 相关理论与研究现状 | `ch02_related_work.md` |
| 第三章 用户需求与系统设计策略 | `ch03_user_research.md` |
| 第四章 刚柔耦合 Kresling 腕关节设计 | `ch04_kresling_wrist.md` |
| 第五章 健—患侧联动控制的模块化假肢腕部系统设计与评价 | `ch05_system_evaluation.md` |
| 第六章 总结与展望 | `ch06_conclusion.md` |

## 工作分工

- **B（写作者）**：按 A 的分节指令提交 Markdown 正文、引用需求和待核验事项。
- **A（总导师）**：审核章节逻辑、重复、证据边界、引用合理性和写作规范，并给出是否通过。
- **C（技术执行）**：仅在 A 审核通过后进行 Markdown 转 LaTeX、BibTeX 处理、格式检查及经授权的版本同步。

## 每章提交内容

每个章节文件开头应保留以下管理信息：

```markdown
<!--
章节：
负责人：B
版本：draft-01
状态：待审核／修改中／A已通过／已转LaTeX
主要输入：
引用状态：已核验 X 条；[VERIFY] X 条
最近审校日期：
-->
```

## 各章输入要求

| 文件 | 主要输入 | 引用重点 | 准入条件 |
|---|---|---|---|
| `ch01_intro.md` | 开题报告、研究问题、真实背景资料 | 用户需求、假肢现状、折纸应用价值 | 1.1—1.3 证据清单完成 |
| `ch02_related_work.md` | 经核验文献笔记、产品与研究案例 | 假肢腕部、Kresling、控制、模块化 | 比较维度与研究缺口明确 |
| `ch03_user_research.md` | 调研方案、匿名化记录、分析材料 | 用户研究方法、需求转译方法 | 样本和伦理状态明确 |
| `ch04_kresling_wrist.md` | 设计草图、结构方案、原型和实验记录 | 构型依据、材料与制造、相关结构研究 | 参数和结果均可追溯 |
| `ch05_system_evaluation.md` | 控制、末端模块、整机、ADL 与可用性材料 | 控制映射、模块设计、评价方法 | 方案、数据与异常完整 |
| `ch06_conclusion.md` | 前五章经审核结论 | 原则上不引入新的核心文献 | 所有结论均有前文证据 |

## 审校状态规则

1. `待审核`：B 已提交但 A 尚未审阅。
2. `修改中`：A 已提出修改意见，尚未通过。
3. `A已通过`：逻辑和证据边界通过，可交给 C 转换。
4. `已转LaTeX`：C 已完成转换和技术检查，不代表学术内容免审。

正文须遵守根目录 `writing_rules.md`，章节结构须与 `outline.md` 保持一致。
